# 09私の環境と、ここまでの道のり

参考までに、私（デイブ田中）がいま使っている環境と、このやり方に落ち着くまでの話です。

## いまの環境（2026年11月）

| もの | 使い方 |
|---|---|
| DaVinci Resolve Studio 21.2 | 編集のすべて。AIもここで働く |
| Claude Code（ClaudeのMaxプラン・モデルはOpus） | AI編集マン。ターミナルで動かし、ResolveをMCPで操作する |
| Mac（Appleシリコン） | 家の編集機。出先からもここのAIに話しかける |
| Blackmagic Cloud・Blackmagic Camera | 出先で撮ったものを、家のResolveに送る |
| 作業用のリポジトリ（フォルダ） | 決まり（このキットのような文書）・文字起こし・直し表・AIが書いた小さな道具を置く。AIはここを読んでから仕事をする |

## このやり方に落ち着くまで

- **最初は、AIに「完成品の動画ファイル」を作らせる方法を試しました**。会話で切る所を決めて、別の道具で書き出す。速いけれど、出てきた動画を人が直す方法がなく、細かい直しができませんでした
- **次に、AIに編集データ（タイムラインのファイル）を書き出させて、Resolveに読み込ませる方法**。人がResolveで直せるようになりました。私はこの仕組みに「KULESHOV（クレショフ）」と名前を付けて育ててきました。このキットのカットの決まり（[03-cut-rules.md](03-cut-rules.md)）は、ここで積み上げたものです
- **いまは、AIがResolveを直接操作する方法**（21.1から）。AIがいつものResolveのタイムラインを組み、人はそれを開いて仕上げる。パワービンの共通素材やテロップのひな形も、そのまま使えます

## 決まりの育て方（KULESHOVで学んだこと）

いちばん効いたのは、**AIが組んだ版と、自分が仕上げた版を比べること**でした。

1. AIが組んだタイムラインは消さずに残す
2. 人は複製したタイムラインで仕上げる
3. 2つを比べて、「AIが削りすぎた所」「AIが残しすぎた所」を数える
4. 何度も出てくる直しを、決まりとして書き足す（例：切り口の余韻0.4秒・0.2秒は、私の直しの84%が「切り口を広げる」だったことから決めました。作者の動画1本での観察です）

最初から完璧な決まりは書けません。AIと一緒に、1本ずつ決まりを育ててください。
