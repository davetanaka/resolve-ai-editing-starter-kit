# 00最初の1本（練習パック）

docs/01の「安全な5分テスト」でAIとつながったら、次はこの練習パックで、粗編集から字幕までを1回通してください。同じ素材と答え合わせの見本があるので、「どこまでうまくいったか」を自分で判断できます。

> 練習パックは、作者（デイブ田中）が実際に撮った4分35秒の素材です。台本の見出しを読み上げたり、独り言を言ったり、何回も言い直したりしています。わざとではなく、本当の撮影でよく起きることです。これをAIがどこまで削れるかが、いちばん試されるところです

---

## 1. 練習パックを落とす

GitHubのこのリポジトリの「Releases」から、`practice-pack-v1.zip` を落として、作業用フォルダの `private-work/` に解凍します。

| 中身 | 何に使うか |
|---|---|
| `practice_v1.mp4` | 練習の素材（1920×1080・30fps・4分35秒） |
| `答え合わせ_残す所と削る所.md` | 見本。残す区間・削る区間・合格の基準 |
| `見本_AI粗編集_v2.srt` | 字幕の見本 |
| `見本_タイムラインのコマ.jpg` | 見本のタイムラインを13コマ並べた画像 |
| `育てた例_AIの版とDaveの仕上げ.md` | 作者が、AIの版を自分の好みまで詰めて、決まりに足した例 |

**答え合わせの見本は、AIに先に読ませないでください**。答えを知った状態で組むと、練習になりません。読ませるのは、5の答え合わせのときです。

## 2. 練習用のプロジェクトを作る

1. DaVinci Resolveで、新しいプロジェクトを作る（名前の例：`練習パック`）。本番のプロジェクトは使わない
2. プロジェクトの設定で、タイムラインを **1920×1080・30fps** にする
3. `practice_v1.mp4` をメディアプールに読み込む

## 3. AIに粗編集を頼む

作業用フォルダでAIを開いて、次の一言を送ります。

```
練習パックで、粗編集を1回通したいです。
このフォルダのAGENTS.md・MY_RULES.mdと、docs/03・04・08を読んでください。
（private-work/ の答え合わせのファイルは、まだ読まないでください）

DaVinci Resolveの「練習パック」のプロジェクトにある practice_v1.mp4 を、
1. 手元で文字起こしして（言葉ごとの時刻つき）
2. 残す所・削る所・人に確認する所を、時刻つきの表で見せてください
3. 私がOKと言ったら、新しいタイムライン「AI粗編集_v1」に並べてください
4. 並べたら、本数・長さ・すき間を読み返して報告し、
   私が音で確かめるべき切れ目の一覧を出してください
```

- 文字起こしのやり方（Resolveの文字起こし、手元で動くWhisper系の道具など）は、AIが提案してきます。初めてなら、AIに「一番手間の少ない方法で」と頼んで大丈夫です
- 表を見て、おかしな所があれば、その場で直してもらいます

## 4. 字幕を作る

```
いま組んだタイムラインの声から、docs/05の決まりで字幕のSRTを作ってください。
1枚ずつに区切った台本を先に見せて、私がOKと言ってからSRTにしてください。
```

できたSRTは、**人がResolveの画面から読み込みます**（字幕トラックとして）。AIからは読み込ませません（docs/05の9）。

## 5. 答え合わせ

1. **音で確かめる**：AIが出した切れ目の一覧を見ながら、1か所ずつ音付きで聞きます。言葉の頭や終わりが欠けていないか、間が不自然でないか。ここは人の耳でしか確かめられません
2. **見本と比べる**：答え合わせのファイルを開いて、「合格の基準」の10の点を1つずつ確かめます。AIに読ませて、比べてもらってもかまいません

```
private-work/ の 答え合わせ_残す所と削る所.md を読んで、
いま組んだタイムラインと比べてください。
合格の基準の10の点について、できている・できていないを表にしてください。
```

全部できていなくても大丈夫です。できていない所が、あなたのAIとあなたの決まりの「育てどころ」です。

## 6. 決まりを育てる

最後に、ここがいちばん大事なところです（docs/11）。

1. AIが組んだタイムラインを複製して、自分の好みのテンポまで詰める（元の版は残す）
2. AIに、2つを比べてもらう

```
「AI粗編集_v1」と、私が詰めた「私の仕上げ」の2つのタイムラインを比べて、
どこをどれだけ詰めたかを数字で出してください。
そのうえで、MY_RULES.mdに足すとよさそうな決まりを、3つまで案を出してください。
足すのは、私がOKと言ってからにしてください。
```

作者が同じことをした結果が、`育てた例_AIの版とDaveの仕上げ.md` です。作者の場合は、切れ目の間を約0.66秒から約0.30秒に詰めていました。あなたの好みは違って当たり前です。
