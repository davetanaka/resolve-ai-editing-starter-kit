# 07画面の置き方・色・音

数字は私の動画（4K・3840×2160・30fps）の例です。考え方を使って、値はあなたの動画に合わせてください。

---

## 1. 置き方の考え方

- **素材は3つだけ**：話している人（トーキングヘッド）・スライドや画面・テロップ。区間ごとに「どの型で置くか」を選ぶだけで配置が決まるように、型をいくつか決めておくと、AIに頼みやすくなります（「この区間は型2で」）
- **下の帯はテロップ用に空けておく**（4Kなら下から約540px）。スライドは作る時点で、下の帯と、顔を置く角を空けて作る
- **素材は、話している人が顔や指を向けている側に置く**（私は画面の右側に映って、左を向いて話すので、素材は左）。左右反転で向きを変えない（文字やロゴが逆になる）
- スライドと顔を左右に並べるときは、上下の位置をそろえる

## 2. 縦長の画面（スマホの画面録画など）

- **横長用の枠に小さく入れない**。縦長の画面が細く浮いて、すかすかに見えます
- 話している人の全画面の上に、**左に大きく重ねる**。下ははみ出してよい（テロップの帯を空けたいなら下を切る）
- ただし、主観（手元を撮った）映像は下に動きがあるので、はみ出させない

## 3. 色

- **画面に出続ける要素の色は、決めた色だけにする**（私は4色：背景・面・濃い色・薄い色）。決めた色と合わない色が隅に居続けると、妙に目立ちます
- 薄い色は、小さい文字には使わない（読みにくい）

## 4. 音

- 書き出したら必ず音の大きさを測る。目安は**−14 LUFS前後・ピークは −1dB以下**。書き出し直しで音が割れたことがあります
- 合成音声を使うときは、低い音を切る（ローカット）

## 5. 色の直し（カラー）

- 話している人のクリップは、カラーグループにまとめて一度に直す（私の順番：明るさ → ガンマ → 肌）
- **色の設定ファイル（.drx）をスクリプトで当てない**。当てたらResolveが落ちました。グレードは人がギャラリーから当てる。カラーグループを作って割り当てるところまでは、AIに頼めます
- 明るさを下げすぎない。窓の白飛びはハイライトだけで抑える

## 6. 見た目をAIに確かめさせる

- AIに、その時刻の画を書き出させて、自分で見て確かめさせる（21.2からAIがコマやサムネの格子を見られる）
- 置いた画面ごとに真ん中の画を書き出して一覧にし、顔切れ・置き違いを先に洗い出す
