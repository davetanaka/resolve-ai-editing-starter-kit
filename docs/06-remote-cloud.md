# 06出先から撮って、家のAIに組ませる（Blackmagic Cloud）

イベントの取材などで、出先で撮ったものを家のResolveに送り、家のAIに粗編集を始めさせる使い方です。私は、発表会から帰宅して4時間26分で公開できました。

## 2つの道（素材の道と、指示の道）

```
素材が届く道：Blackmagic Camera → Blackmagic Cloud → 家のResolve
指示が届く道：スマホのアプリ → 家のMacのAI（Claude Code） → Resolve
```

Blackmagic Cloudが運ぶのは素材だけです。家のAIに話しかける道は、別に用意します（下の「私の例」）。家で編集するだけなら、どちらも要りません。

## 流れ（3つの段に分けて確かめる）

**段1：カメラ → Blackmagic Cloud**
1. 家のMacで、Blackmagic Cloudのプロジェクトを作っておく
2. 出先で、スマホの**Blackmagic Camera**（またはBlackmagicのカメラ）の設定で、Blackmagic Cloudにサインインし、送り先にそのプロジェクトを選ぶ。カメラの設定では、**プロキシ（軽い版）だけを送るか、元のファイルも送るか**を選べます。私はプロキシだけにしています（会場の回線で送れる大きさにするため）
3. 確かめ方：カメラのメディアの画面で、クリップにクラウドの印が付いているか

**段2：Blackmagic Cloud → 家のMac**
4. 家のMacのResolveで、そのクラウドのプロジェクトを開いておくと、届いたクリップが「Camera Uploads」ビンに入ってきます
5. 確かめ方：Camera Uploadsビンに、撮った本数が並んでいるか

**段3：家のAIがResolveで見る**
6. スマホから家のAIに話しかける（「いま撮ったの届いた？」）。家のAIがResolveを見て答え、文字起こしや粗編集を始める
7. 確かめ方：AIに、届いたクリップの名前と長さを一覧にさせる

**帰宅したら**
8. **元のファイル（本体）をMacに入れて、つなぎ直す**。プロキシだけを送った場合、家にあるのはプロキシだけです。編集中は気づきませんが、そのまま書き出すと「メディアオフライン」になります。カメラの記録メディアから本体をコピーし、AIに「この本体とプロキシに、つなぎ直して。長さと頭のタイムコードが同じかを確かめて」と頼みます（つなぎ直しは「既定で禁止」の操作なので、案を見せさせてからOKする）
9. 人が仕上げて、書き出す

> スマホから家のAIに話しかけるには、家のMacのAIをスマホから操作できるしくみが要ります。**私の例**：家のMacでは「Orca」というアプリの中でClaude Codeを動かし、スマホやタブレットのOrcaのアプリから、Tailscale（自分の機器どうしだけをつなぐ仕組み）で家のMacに直接つないでいます。Claude Code自体のリモート操作の機能は、予備にしています。使えるアプリや仕組みはよく変わるので、あなたのAIにも「スマホから、家のMacのClaude Code（またはCodex）を使う方法を教えて」と聞いて、いまの方法を確かめてください。家のMacを外から操作できるようにするので、**強いパスワードや二段階の認証を使う・知らない回線で丸見えにしない・家にいないときは読むだけの作業から始める**、を守ってください。AIを止めたいときの一言（「いまの作業を止めて、何もしないで」）も決めておきます

## 出かける前のテスト（家の中で）

スマホのWi-Fiを切って、携帯の回線にしてから試すと、出先と同じ条件になります。

1. スマホから家のAIに話しかけて、Resolveで開いているプロジェクトの名前を答えさせる
2. 短いクリップを1本撮って送り、家のResolveのCamera Uploadsビンに届くかを見る
3. 届いたクリップの名前と長さを、AIに一覧にさせる
4. AIに「いまの作業を止めて、何もしないで」と送って、止まるかを確かめる

## つまずきやすい所（私が実際にあったこと）

- **家のResolveでクラウドのプロジェクトを開いていないと、Camera Uploadsビンに入ってこない**（クラウドには上がっています）。家のResolveは、そのプロジェクトを開いたままにしておく
- **2本目以降が送られないことがあった**。カメラ（アプリ）を開き直すと送られた
- **回線が細いと、長いクリップが上がらない**。会場の無料の回線では、長い1本が上がりきらなかった。短く分けて撮る、回線を用意する、など
- **いつものパワービンが見えなかった**（クラウドのプロジェクトで）。共通素材やテロップのひな形をパワービンに入れている人は、クラウドのプロジェクトで見えるか、先に確かめておく（原因は確かめ中）
