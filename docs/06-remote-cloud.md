# 06 出先から撮って、家の AI に組ませる（Blackmagic Cloud）

イベントの取材などで、出先で撮ったものを家の Resolve に送り、家の AI に粗編集を始めさせる使い方です。私は、発表会から帰宅して4時間26分で公開できました。

## 流れ

1. 家の Mac で、Blackmagic Cloud のプロジェクトを作っておく（Resolve を開いたままにしておく）
2. 出先で、スマホの **Blackmagic Camera**（または Blackmagic のカメラ）で撮り、送り先にそのクラウドのプロジェクトを選ぶ
3. 撮ったものの軽い版（プロキシ）が、家の Resolve の「Camera Uploads」ビンに届く
4. スマホから家の AI に話しかける（「いま撮ったの届いた？」）。家の AI が Resolve を見て答え、文字起こしや粗編集を始める
5. 帰宅したら、本番の高画質の素材に差し替えて、人が仕上げる

> スマホから家の AI に話しかけるには、家の Mac の AI をスマホから操作できるしくみ（リモートで使えるターミナルやアプリなど）が要ります。私は家の Mac の AI に、スマホからつないで話しかけています

## つまずきやすい所（私が実際にあったこと）

- **家の Resolve が閉じていると、素材が届かない**。開いたままにしておく
- **2本目以降が送られないことがあった**。カメラ（アプリ）を開き直すと送られた
- **回線が細いと、長いクリップが上がらない**。会場の無料の回線では、長い1本が上がりきらなかった。短く分けて撮る、回線を用意する、など
- **いつものパワービンが見えなかった**（クラウドのプロジェクトで）。共通素材やテロップのひな形をパワービンに入れている人は、クラウドのプロジェクトで見えるか、先に確かめておく（原因は確かめ中）

## 料金の目安（2026年11月時点・変わることがあります）

- Blackmagic Camera：無料
- Blackmagic Cloud：月額（私は月1,966円のプラン）。最新の料金は公式サイトで確かめてください
