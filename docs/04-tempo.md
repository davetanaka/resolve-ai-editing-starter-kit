# 04テンポの決まり

ここに書いた数字は、**私の動画（落ち着いて語るタイプのトーキングヘッド）での実測と初期値**です。あなたの動画に合わせて変えてください。変えたいときは、この文書ではなくMY_RULES.mdに「私はこうする」と書いておくと、AIが次からそちらに従います。

---

## 1. どのテンポを選ぶか

- 私は「落ち着いた語り型」を選んでいます。目安は**1分に1〜3回ほどの切り替え、1つの画の長さの中央値12〜23秒**
- 同じくらいの規模のチャンネルを調べたところ、テンポの速さと再生数ははっきり結びついていませんでした。速くすることを目標にしていません
- 大事なのは速さより、**途中で迷わせないこと**と、**同じ画が止まり続けないこと**

## 2. 間（ま）の長さ

| 場所 | 目安 |
|---|---|
| 言葉の前後の余白 | **最大1.5秒ほど**。クリップの途中の長い無音は抜く |
| 文の中の短い考える間（0.35秒未満） | 残す |
| 文の中の長い迷い（0.8秒より長い） | 0.25〜0.45秒に縮める（ゼロにしない） |
| 文と文の間 | 0.35〜0.7秒 |
| 強調・驚き・結論の前後 | 0.5〜1秒あってよい |
| 章や話題の切り替え | 0.6〜1.2秒残し、画や音でも切り替えを示す |

- AIの版は余白を取りすぎることがありました（私の実測：AI 2.9秒・4.2秒 → 私の仕上げ1.6秒・1.7秒）
- 「切り口の余韻（言葉の後0.4秒・前0.2秒）」は、切ってよい最小の幅です。「最大1.5秒」は余白の上限です。別の話なので混ぜないように

## 3. 速く見せる所・遅く見せる所

- **速く**：理屈の説明、手順、前提の共有（無音・フィラー・言い直しを詰める）
- **遅く**：大事な気づき、いちばん伝えたいこと、問いかけの直後（余白を残して、考える時間をあげる）

## 4. 冒頭

- **最初の30〜60秒で、「この動画で何が得られるか」「どんな人の役に立つか」「見続ける理由」を示す**
- 長い挨拶・経歴・チャンネル紹介は冒頭に置かない（必要なら本題のあとに短く）
- 自分の結論（どう見たか）を一言で言ってから、中身に入る
- 名乗りは1文で終える

## 5. 画を止めない

- **同じ画が15秒以上止まらない**ようにする（切り替えでなく、ゆっくり寄るだけでもよい）
- 同じ配置が45秒以上続かないようにする
- カットの代わりに「寄り」で動かす手もあります（私の例：100%から104〜106%へ、5〜6秒かけてゆっくり寄る。1分に1回弱）

## 6. その他

- **価格のように、すぐ古くなる数字は話さない**。画面の文字と概要欄に置く（古くなったら、そこだけ直せる）
- 尺の目安：AIの版が、人の仕上げより1割以上長くならないことを目標に、決まりを育てています
