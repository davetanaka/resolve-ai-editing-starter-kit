# 05テロップの決まり

話した言葉をそのまま出す「フルテロップ」をAIに起こしてもらうときの決まりです。

---

## 1. いつ作るか

- **テロップは最後に作る**。元にするのは台本ではなく、**人が仕上げたタイムラインの声**です。人がカットを詰めると、テロップの区切りも時刻も変わるので、先に作ると作り直しになります
- 流れ：仕上げたタイムラインをAIが読む → 残った区間の言葉を、文字起こしの時刻から拾う → 1枚ずつに区切った台本（1行＝1枚）を作る → 直してから、時刻を付けてSRTにする → Text+ などでタイムラインに置く
- 台本はMarkdownでなくテキスト（.txt）で作る（Markdownは改行が見えにくくなるため）

## 2. 字数と行数

- **1行20字まで、1枚2行まで。目指すのは1行**。2行にするのは、ひと息の言葉が20字を超えるときだけ
- 20字は、4Kの画面・文字の大きさ120pxで、画面の幅の約6割です

## 3. どこで区切るか（いちばん大事）

- **節の終わり（文の終わり・「〜て」「〜けど」「〜ので」などの終わり）で区切る。字数をそろえるより、こちらを優先する**
- **行の終わりに、次の節の頭を入れない**。例：「だから」「ちょっと」「例えば」を前の枚の最後に入れず、次の枚の頭に送る
  - AIは字数をそろえようとして、次の節の頭まで取り込みがちです。私はそれを「文章と文章の合体」と呼んで、毎回直していました
- **切ってはいけない所**：言葉の途中／行の頭に助詞が来る所／修飾の途中／ひとつながりの言葉（例「AIマインド｜クリップ」）／英語の製品名の途中
- 短すぎる切れ端は、前の枚に入れるか後ろの枚に送る

## 4. 句読点と記号

- 「、」は半角スペースにする
- 「。」は使わない（枚の終わりなら取る。枚の途中で文が終わるなら半角スペース）
- 疑問は全角の「？」
- 製品名・機能名・キーワード・口に出したセリフは「」で囲んでもよい
- 補足は（）で
- **日本語と英数字の間に半角スペースを入れない**（「Gen 3は」であって「Gen 3は」ではない）。英数字どうしの区切りは残す

## 5. 聞き違いの直し

- **製品名は公式の表記にする**（例：「ダビンチリゾルブ」→「DaVinci Resolve」）
- **直し表を作る**：「聞き違い → 正しい表記」の一覧（タブ区切りのファイルなど）を作り、AIにテロップへ当てさせる。動画のたびに増やしていく
- **推測が入る直しは、確実な直しと混ぜない**。音を聞かずに字面から推した直しには「要確認」の印を付け、一覧にして、最後に人の耳で決める。推測で入れた直しが全部のテロップに当たって、そのまま公開してしまったことがあります
- 迷う言葉は、その部分の音だけ切り出して、別の文字起こしの道具でも起こし直して比べる。2つとも同じで意味も通るなら、本人がそう言ったものとして残す
- **本人の言葉を「こう言いたかったはず」と直さない**

## 6. 言い間違い

- 言い直したテイクがない言い間違い（名前の取り違え・数字の言い間違い）は、**切らずに「×誤 ○正」のテロップで補う**（例「×5.2キロ ○5.8キロ」）
- 言いよどんで欠けた言葉は、括弧で補う（例「お椀で（丸く盛ろうと）成形して」）
- 「〜ぐらい」の付いた、だいたいの数の言い揺れは直さない。直すのは、そのままだと見た人が間違った事実を覚えるものだけ

## 7. 機械で確かめること

置く前に、AIに次を確かめさせる。

- 20字を超える行がないか（超えたら警告）、3行以上の枚がないか（エラー）
- 全角の英数字・半角のカタカナが混ざっていないか
- 数字と単位の間に空白が入っていないか、行の前後に空白がないか
- 括弧の閉じ忘れがないか
- 置いたあと、全部の枚の開始と長さがSRTどおりか

## 8. 見た目（私の例）

見た目はチャンネルのデザインに合わせて、あなたの決まりにしてください。私の例です。

- 書体：源暎ゴシック、4Kで120px。文字は濃い紺（#2F526D）、縁取り・影なし
- 下に敷く座布団：背景と同じグレージュ（#EFEBE5）・不透明度70%・角丸
- 位置：下端をそろえ、2行のときは上へ伸ばす
- 強調したい言葉（数字・製品名・決め台詞）だけ、薄い青（#0882A3）で少し大きく。多すぎると効かないので、1分に1〜2か所まで

## 9. Resolveに置くときの注意（AI向け）

- **基本のやり方：AIがSRTを作り、人が画面から読み込む**（字幕トラックとして置く・書式はResolveの字幕の設定で）。初めての人はこれから
- 下の「DRTを書き換えてText+ を置く」方法は、**上級・実験的なやり方**です（21.2 Build 5での私の例）。試すときは、必ずタイムラインの複製と控えを取ってから

- Text+ はメディアプールに置けません。スクリプトで1枚ずつ挿入すると、後ろのクリップが全部ずれることがあります
- 私は「タイムラインをDRTで書き出す → 中のXMLに、書式を整えたText+ を枚数分複製して時刻を書く → 新しいタイムラインとして読み込む」という方法で、数百枚を時刻どおりに置いています
- SRTの字幕トラックは、スクリプトから付け直すとResolveが落ちたことがあります。字幕トラックにするなら、SRTの読み込みは人が画面から行う
- 作業の前に、タイムラインをDRTで書き出して控えておく
