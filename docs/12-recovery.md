# 12失敗したときの戻し方

AIに任せた作業がおかしくなったときの戻し方です。**戻せるのは、控えを取ってあったときだけ**です。作業の前の控え（AGENTS.mdの「本番の前の控え」）を、必ず取ってください。

---

## まず止める

AIがおかしな動きをしていたら、すぐにこう送ります。

```
いまの作業を止めてください。これ以上、何も変更しないでください。
ここまでに何をしたかを、順番に一覧にしてください。
```

Claude CodeならEscキーでも止まります。止めたら、一覧を見て、何が変わったかを確かめます。

## 戻し方（小さい順に）

| 何がおかしいか | 戻し方 |
|---|---|
| 作業用に複製したタイムラインがおかしい | その複製は使わず、元のタイムラインからもう一度複製し直す（元には触っていないはず） |
| タイムラインを元に戻したい | `backup/`のDRTを、Resolveのメニュー ファイル ＞ 読み込み ＞ タイムライン で読み込む（新しいタイムラインとして入る） |
| プロジェクトごとおかしい | プロジェクトマネージャーで、`backup/`の .drpを読み込む（別のプロジェクトとして入る）。元のプロジェクトは、念のため名前を変えて残しておく |
| 素材が「メディアオフライン」になった | 素材のファイルを消したのでなければ、つなぎ直しで戻ります。AIに「オフラインのクリップを一覧にして。元のファイルがどこにあるかも探して。まだつなぎ直さないで」と頼み、案を見てからOKする |

## Resolve自体の控え

- Resolveは、プロジェクトを自動で控える機能を持っています（環境設定 ＞ ユーザー ＞ プロジェクトの保存と読み込み）。オンにしておくと、もしもの時に助かります
- 大事なプロジェクトは、AIに触らせる前に .drpで書き出しておくのがいちばん確実です

## 失敗から決まりを育てる

失敗したら、それも決まりにします。

```
今日の失敗の原因と、次から防ぐための決まりを、MY_RULES.mdに書き足す案として出してください。
```
