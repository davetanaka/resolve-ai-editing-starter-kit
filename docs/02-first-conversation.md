# 02 AIとの会話の進め方

AIにいきなり「編集して」と頼むより、**4つの段階**に分けたほうが、ずっとうまくいきます。

1. **調べさせる**（まだ何も変えさせない）
2. **案を見せさせる**（表で）
3. **OKを出してから、作らせる**
4. **自分の目で確かめさせてから、報告させる**

人がやるのは、2の案を見てOKを出すことと、最後に仕上げることです。

---

## 1. 調べさせる

```
DaVinci ResolveのMCPで使える道具を一覧にして、それぞれ何ができるかを日本語で説明してください。
新しい機能は、Resolve側の「新しい機能の説明」と「スクリプトのAPIの説明」を使って調べてください。
まだプロジェクトやタイムラインは何も変更しないでください。
```

```
いま開いているプロジェクトの中身を教えてください。
タイムラインの一覧と、メディアプールにある素材（名前と長さ）を表にしてください。
何も変更しないでください。
```

## 2. 案を見せさせる

```
メディアプールの「（クリップ名）」は、私がカメラに向かって話している動画です。
文字起こしをして、話の段落ごとに「残す／削る」の案を表にしてください。
削る理由（言い直し・同じ話の繰り返し・長い無音 など）も一言ずつ。
カットの決まりはdocs/03-cut-rules.mdに従ってください。
まだタイムラインは作らないでください。
```

- 表を見て、「ここは残して」「ここはもっと削って」と返します。何往復してもかまいません
- 大きく段落ごと削る判断は、AIに任せずに人が決めます（AIには「迷ったら案として聞いて」と頼んでおく）

## 3. 作らせる

```
さっきの案でOKです。新しいタイムライン「粗編集_v1」を作って、残す所だけを並べてください。
段落の頭には、マーカーを打って段落の名前を書いてください。
私の元のタイムラインには触らないでください。
```

## 4. 確かめさせる

```
並べたタイムラインを読み返して、置いた本数・全体の長さ・すき間がないかを確かめてください。
それから、何か所かコマを書き出して、思ったとおりに並んでいるかを目で見て確かめてから報告してください。
```

- Resolveは、操作が思ったとおりにいかなくても「成功」と返すことがあります。読み返しとコマの確認は、毎回やらせてください

---

## 続けて頼めること（例）

### テロップを起こす

```
「粗編集_v1」の話している内容から、テロップを起こしてください。
決まりはdocs/05-telop-rules.mdに従ってください。
まずSRTファイルとして書き出して、私に見せてください（まだタイムラインには置かないでください）。
製品名などの聞き違いで、推測が入る直しは、別の一覧に分けてください。
```

### 人が直したあとに、AIに合わせ直させる

```
私が「粗編集_v1」を複製した「仕上げ_v1」を手で詰めました。
仕上げ_v1の今の並びに合わせて、テロップを起こし直してください。
```

> コツ：AIが組んだ版は消さずに残し、人は複製した版で直す。あとで2つを比べると、AIに足りなかった自分の好みが見えます。それをMY_RULES.mdに書き足すと、次の回からAIが覚えた状態で始められます

### 自分の決まりを書き足させる

```
今日私が直した所を見て、私の編集の好みとしてMY_RULES.mdに書き足すとよいことを、3つまで提案してください。
書き足すのは、私がOKと言ってからにしてください。
```
