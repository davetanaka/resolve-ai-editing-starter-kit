# 13用語集

このキットに出てくる言葉の、ざっくりした意味です。

| 言葉 | 何か | 覚えておくこと |
|---|---|---|
| AI（AI編集マン） | Claude CodeやCodexなど、ターミナルで動くAI。あなたの代わりにResolveを操作する | Resolveの外にいて、MCPを通して話しかける |
| MCP | 外のAIが、Resolveを操作するための入口（仕組みの名前） | Resolveのメニュー「Setup AI Assistants」で、AIに登録する |
| スクリプト | AIが書く、Resolveを操作する小さなプログラム（Python） | AIが書いて動かす。あなたは書かなくてよい（docs/10） |
| `run_script_unsafe` | ファイルの読み書きや、外のプログラムまで扱える、制限なしのスクリプト実行 | 既定で禁止。使うときは中身を見せさせてから（AGENTS.md） |
| タイムライン | 編集の並び（いつものResolveの画面） | AIは、元を残して複製で作業する |
| DRT | タイムライン1本の控えのファイル | タイムラインを戻すときに使う。プロジェクト全体は守らない |
| .drp | プロジェクト全体の控えのファイル | 設定・ビン・グレードまで守る。AIに触らせる前に書き出す |
| SRT | テロップ（字幕）の文字と時刻だけのファイル | AIに作らせて、人が画面から読み込むのが基本（docs/05） |
| Text+ | Resolveの、書式を付けられる文字の部品 | テロップをText+ で置くのは上級のやり方（docs/10レシピ1） |
| パワービン | どのプロジェクトからでも使える、共通の素材の置き場 | AIは読めるが、登録は人が行う |
| プロキシ | 編集を軽くするための、小さい版の動画 | 書き出しの前に、本体（元のファイル）につなぎ直す（docs/06） |
| Blackmagic Cloud | 出先で撮ったものを、家のResolveに届けるしくみ | 共有のプロジェクトは、ほかの人の作業にも響く |
| MY_RULES.md | あなたの決まりを書き足すファイル | ここを育てる（docs/11） |
