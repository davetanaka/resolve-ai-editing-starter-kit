# 10 AIにスクリプトを書かせるレシピ

このキットには、プログラム（スクリプト）は入っていません。代わりに、**あなたのAIに、あなたの環境で動くスクリプトを書かせるための頼み方**を入れています。

AI（Claude Codeなど）は、DaVinci Resolveの「AIアシスタント」の仕組み（MCP）を通して、Pythonのスクリプトを自分で書いて動かせます。私の動画の編集（テロップ330枚、図の差し込み、左上のラベル）も、全部AIがその場で書いたスクリプトで組みました。

人が書いたスクリプトをそのまま配るより、AIにあなたのMac・フォント・フォルダに合わせて書かせる方が、環境には合わせやすくなります。ただし、AIが書いたスクリプトは確かめられていません。中身を見せさせ、複製したタイムラインで動かし、終わったら結果を点検させてください（AGENTS.mdの「既定で禁止」も守らせます）。

---

## 使い方

> ここにあるレシピは、私の動画（4K・話している人が中心・左上にラベル）での例です。あなたの画面の型に合わせて、AIと相談しながら読み替えてください。初めてなら、**何も変えないレシピ5（点検）から**試すのが安全です

1. 下のレシピから1つ選び、「頼む一言」をAIに送る
2. AIが案（何をどう作るか）を見せてきたら、確かめてOKを出す
3. できたら、「確かめ方」の項目をAIに確かめさせる
4. うまくいったスクリプトは、このフォルダの中に保存させる（次から使い回せる）

> どのレシピも、作業は**複製したタイムライン**で行います。元のタイムラインには触らせません（AGENTS.mdの決まり）

---

## レシピ1：テロップを自動で置く（上級・実験的）

> 初めての人は、まず「AIにSRTを作らせて、自分で画面から読み込む」形にしてください（docs/05の9）。下は、私が数百枚をText+ で置いているやり方です

**頼む一言**
```
仕上げたタイムラインの声から、テロップを作って置いてください。
テロップのひな形は、パワービンの「（ひな形の名前）」です。
docs/05-telop-rules.mdとdocs/08-transcription.mdの決まりに従ってください。
まずタイムラインを複製し、作り方の案を見せてから始めてください。
最初は、頭の1分ぶんだけ置いて見せてください。
```

**作ってもらうもの**
- タイムラインの並びどおりに声をつないで文字起こし（言葉ごとの時刻つき）→ 1枚ずつに区切る → SRTにする
- Text+で置く。Text+はメディアプールに置けないので、**タイムラインをDRTで書き出し、中のXMLにひな形のText+を複製して取り込み直す**方法が確実でした
- 書式（文字の大きさ・色・座布団）は、あなたが作ったひな形のText+を1つ用意し、それを複製させる

**確かめ方**
- 置いた枚数・それぞれの頭と終わりが、SRTと1フレームもずれていないか
- テロップとテロップの間に隙間がないか（長く話していない所を除く）
- 数字（21.2）・英単語・「っていう」の途中で改行していないか

## レシピ2：粗編集を組む

**頼む一言**
```
「（ビンの名前）」のビンの撮影素材から、粗編集のタイムラインを新しく組んでください。
docs/03-cut-rules.mdとdocs/04-tempo.mdの決まりに従ってください。
先に、残す所と切る所の一覧（時刻つき）を見せてください。
```

**作ってもらうもの**
- 文字起こし → 言い直し・言いよどみ・長い無音を切る案 → 新しいタイムラインに並べる
- 切り口に余韻を残す（docs/03）

**確かめ方**
- 映像と音声の本数・頭・終わりがそろっているか（映像だけ合って音声がずれることがある）
- 切れ目の前後を音付きで聞いて、言葉の頭や終わりが欠けていないか・間が不自然でないか。AIは音の大きさは測れても、言葉が欠けたかまでは聞き分けられないことが多いので、AIに切れ目の時刻の一覧を作らせ、人が聞いて確かめる
- 書き出したコマで見るのは、構図・黒い画・重なり（コマでは音の欠けは分からない）

---

## レシピ3：左上のラベル（コーナー名）を出す

**頼む一言**
```
左上に、動画の題とコーナー名の2段のラベルを出したいです。
背景が透明な動画で作り、空いている映像トラックに、コーナーごとに置いてください。
題は「（動画の題）」、コーナー名と時刻は、このあと一覧で渡します。書体は「（書体の名前）」です。
```

**作ってもらうもの**
- 文字だけの透明な動画（PNGから作る）をコーナーの長さぶん作り、新しいトラックに置く
- 画像や動画のファイルを作るので、AIはffmpegなどの道具を使い、ファイルを書く許可を求めてきます

**確かめ方**
- 読み込んだ透明な動画の「アルファの扱い」が**Straight**になっているか（そのままだと下の画全体が白っぽく浮く）
- 図や画面を大きく出している間は、ラベルを出さない（かぶって読みにくくなる）

---

## レシピ4：図や画面を左に、顔を右に出す

**頼む一言**
```
この区間に、この図（画像）を左に大きく、話している私の顔を右の角丸の枠に出したいです。
話している映像のクリップは切らずにできる方法で組んでください。
まず1区間だけ作って、コマを書き出して見せてください。
```

**作ってもらうもの**
- 地の色の全画面の画に、左に図、右に角丸の「窓」（透明な穴）をあけた透明な動画を作り、話している映像の上に重ねる
- 窓の中の顔の大きさは、話している映像の複製を下に置き、拡大と位置で合わせる

**確かめ方**
- 窓の中に顔がちょうど収まっているか（書き出したコマを見る）
- テロップの帯（画面の下）と図がぶつかっていないか

---

## レシピ5：置いた後の点検

**頼む一言**
```
タイムライン全体を点検してください。直さずに、問題の一覧だけを見せてください。
```

**点検してもらうこと**
- サウンドロゴ（コーナーの区切りの音）があれば、その区間に、画像や動画が1フレームもかかっていないか
- 同じトラックで素材が重なっていないか
- テロップの隙間・ラベルと図のかぶり
- 全体を20秒おきくらいにコマで書き出し、見た目のおかしな所

---

## うまくいかないとき

- **AIが「成功」と言っても信じない**。必ず読み返しとコマの書き出しで確かめさせる（AGENTS.mdの決まり）
- Resolveに確認の窓（ダイアログ）が出ていると、操作が止まります。止まったら、まず窓を閉じる
- 使っている素材のファイルを上書きさせない。作り直すときは別の名前で作り、差し替える
